# Fractalic Chat Agent Implementation Plan

## Архитектура чата

### Backend (UI Server расширение)
1. **WebSocket endpoint**: `/ws/chat` для реального времени
2. **Chat API**: `/api/chat/` для REST запросов  
3. **Session management**: Сохранение истории чатов
4. **Fractalic integration**: Выполнение скриптов через существующий `/ws/run_fractalic`

### Frontend (Простой HTML/JS)
1. **Chat interface**: Список сообщений + поле ввода
2. **Code visualization**: Показ выполняемых Fractalic скриптов
3. **Live execution**: Стрим вывода выполнения в реальном времени
4. **File browser**: Просмотр сгенерированных файлов

### Интеграция с Fractalic
- Пользователь пишет текстовый запрос в чат
- Система генерирует Fractalic script для выполнения запроса  
- Показывает пользователю сгенерированный скрипт
- Выполняет скрипт через `/ws/run_fractalic`
- Стримит результат в чат интерфейс
- Сохраняет результат в сессию
