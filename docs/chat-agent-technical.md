# Fractalic Chat Agent - Техническая документация

## Обзор

Fractalic Chat Agent - это интеллектуальный чат-интерфейс, который позволяет пользователям взаимодействовать с Fractalic через естественный язык с полной прозрачностью процесса выполнения.

## Архитектура

### Backend (UI Server расширение)

**WebSocket Endpoint: `/ws/chat`**
- Реального времени двусторонняя связь
- Управление подключениями и сессиями 
- Интеграция с Fractalic execution pipeline

**HTTP Endpoint: `/chat`**
- Обслуживание HTML интерфейса
- Статический файл `fractalic_chat.html`

### Frontend (HTML/CSS/JS)

**Основные компоненты:**
- Интерфейс чата с сообщениями
- WebSocket клиент для реального времени 
- Визуализация кода и выполнения
- Индикатор подключения

## Поток выполнения

1. **Пользователь отправляет запрос**
   - Текстовое сообщение через веб-интерфейс
   - Отправка через WebSocket

2. **Генерация Fractalic скрипта**
   - Автоматическое создание markdown скрипта
   - Отображение сгенерированного кода пользователю

3. **Выполнение скрипта**
   - Создание временного файла
   - Запуск через `fractalic.py`
   - Потоковая передача вывода

4. **Отображение результатов**
   - Реального времени вывод выполнения
   - Статус выполнения и результаты
   - Сохранение в истории чата

## API Сообщений WebSocket

### Входящие сообщения (клиент → сервер)

```json
{
  "type": "user",
  "message": "Текст запроса пользователя"
}
```

### Исходящие сообщения (сервер → клиент)

**Сообщение пользователя:**
```json
{
  "type": "user",
  "message": "Текст сообщения",
  "timestamp": "2025-01-XX:XX:XX"
}
```

**Ответ ассистента с кодом:**
```json
{
  "type": "assistant", 
  "message": "Я сгенерировал следующий скрипт...",
  "timestamp": "2025-01-XX:XX:XX",
  "script_content": "# Markdown содержимое скрипта"
}
```

**Статус выполнения:**
```json
{
  "type": "execution",
  "message": "🚀 Выполняю скрипт...",
  "timestamp": "2025-01-XX:XX:XX", 
  "status": "running|completed"
}
```

**Вывод выполнения:**
```json
{
  "type": "execution_output",
  "message": "Текст вывода выполнения",
  "timestamp": "2025-01-XX:XX:XX"
}
```

**Ошибка:**
```json
{
  "type": "error",
  "message": "Описание ошибки",
  "timestamp": "2025-01-XX:XX:XX"
}
```

## Интеграция с существующими компонентами

### UI Server
- Использует существующий `/ws/run_fractalic` функционал
- Интегрируется с файловой системой и Git
- Доступ к MCP инструментам

### Fractalic Execution Engine
- Выполнение через `fractalic.py`
- Поддержка всех операций (@llm, @return и др.)
- Стриминг вывода с UTF-8 поддержкой

### MCP Manager
- Доступ ко всем внешним инструментам
- OAuth интеграция для сервисов
- Расширенные возможности агента

## Развертывание и запуск

### Требования
- Python 3.8+
- FastAPI
- WebSockets поддержка
- Работающий UI Server

### Запуск
```bash
# Из корневой директории fractalic
./test_chat.sh

# Или вручную
python3 -m uvicorn core.ui_server.server:app --host 0.0.0.0 --port 8000
```

### Доступ
- **Чат интерфейс:** http://localhost:8000/chat
- **WebSocket:** ws://localhost:8000/ws/chat
- **API информация:** http://localhost:8000/info
