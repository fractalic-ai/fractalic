# 🤖 Fractalic Chat Agent

Интеллектуальный чат-интерфейс для Fractalic с полной прозрачностью процесса выполнения.

## ✨ Что это такое?

Fractalic Chat Agent - это революционный подход к взаимодействию с AI, где пользователь может:

- 💬 **Общаться на естественном языке** - просто опишите, что вы хотите сделать
- 👀 **Видеть генерируемый код** - система показывает Fractalic скрипт, который будет выполнен
- ⚡ **Наблюдать выполнение в реальном времени** - смотрите, как ваш запрос обрабатывается пошагово
- 🔍 **Полная прозрачность** - нет "черного ящика", вы видите каждый этап

## 🚀 Быстрый старт

### Требования
- Python 3.8+
- Работающий Fractalic (клонированный репозиторий)
- Базовые зависимости FastAPI

### Запуск за 30 секунд

```bash
# 1. Перейдите в директорию Fractalic
cd /path/to/fractalic

# 2. Запустите чат
./test_chat.sh
```

Автоматически откроется браузер с интерфейсом чата!

### Альтернативный запуск
```bash
# Активировать venv (если есть)
source .venv/bin/activate

# Установить зависимости (если нужно)
pip install fastapi websockets uvicorn

# Запустить сервер
python3 -m uvicorn core.ui_server.server:app --host 0.0.0.0 --port 8000

# Открыть http://localhost:8000/chat
```

## 🎯 Как это работает

### 1. Пользователь задает вопрос
```
"Создай для меня простую веб-страничку с информацией о погоде"
```

### 2. Система генерирует Fractalic скрипт
```markdown
# Weather Page Generator {id=main}

@llm
model: gpt-3.5-turbo
prompt: |
  Создай HTML страницу с информацией о погоде.
  Сделай ее красивой и современной.
to: weather_page

# Generated Page {id=weather_page}

@return
blocks: weather_page
```

### 3. Скрипт выполняется
- Пользователь видит сгенерированный код
- Система выполняет скрипт через Fractalic engine
- Весь вывод стримится в чат в реальном времени

### 4. Результат
- Готовая веб-страница
- Полная история выполнения
- Возможность модификации и повтора

## 🏗️ Архитектура

### Backend
- **WebSocket `/ws/chat`** - реального времени связь
- **HTTP `/chat`** - интерфейс чата
- **Интеграция с UI Server** - использует существующую инфраструктуру
- **Fractalic Engine** - выполнение сгенерированных скриптов

### Frontend  
- **Modern HTML/CSS/JS** - отзывчивый интерфейс
- **WebSocket Client** - двусторонняя связь
- **Code Highlighting** - подсветка Fractalic кода
- **Real-time Streaming** - живое отображение выполнения

## 🔧 Кастомизация

### Изменение шаблонов скриптов
Отредактируйте функцию `generate_fractalic_script_for_request()` в `core/ui_server/server.py`

### Стилизация интерфейса
Модифицируйте CSS в `fractalic_chat.html`

### Добавление новых типов сообщений
Расширьте WebSocket handler в `websocket_chat_endpoint()`
